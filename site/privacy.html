privacy

last updated 22 november 2026

stash is a discord bot that saves links posted in a #read-later channel and sends some of them back on a schedule. this page explains what it stores, why, and who else sees it. if anything here is unclear, email hi@bennett-eghan.com.

what stash reads

  • messages in #read-later, to find links in them. other text in those messages is not stored.
  • messages in the notes threads stash opens for saved links. those are stored as notes.
  • reactions (✅ and 👍) on its own messages and on posts in #read-later.

stash does not read other channels or direct messages.

what stash stores

  • discord ids: the server, the person who saved each link, and the message and thread ids needed to connect reactions and notes back to a link.
  • saved links: the url, plus the page's title, description and estimated reading time, which stash fetches from the page itself.
  • notes: the text of messages written in a link's notes thread, with who wrote them.
  • reading state: whether a link is unread, read, loved or archived, how many times it has been sent, and which links went out in which drop.
  • tags: topic tags, only if the server has added an ai key with /setkey.
  • server settings: drop days, time and timezone, personal or shared mode, an optional alert channel, and the ai provider and model if one is set.
  • ai keys: if a server adds one with /setkey, it is stored encrypted and used only to tag that server's links.

who else sees it

  • discord, which carries every message, reaction and command, including keys typed into the /setkey form.
  • railway, which hosts the bot and its database in the united states.
  • the websites you save. when fetching a page's title, stash's server visits that page like a browser would. the site sees the server's address, not yours.
  • the ai provider a server chooses (claude, openai, gemini, deepseek or openrouter), only if the server added a key. for each new link, stash sends the url, title, description and the existing tags, and nothing else. that provider's own privacy policy applies.
  • the host receives an alert when a scheduled drop fails, with the server's name and id, a user id and the reason.

stash does not sell data, show ads or use analytics or trackers. this website loads its font from google fonts.

who can see your links

in a personal server, your saved links, picks and reactions are yours; other people in the server don't get them in their drops. in a shared server, everyone's links go into one pile that the whole server sees, with the name of who saved each one. links you post in #read-later are visible in discord to anyone who can see that channel either way.

keeping and deleting data

  • deleting a message in a notes thread deletes that note. deleting the thread deletes its notes.
  • /setkey with remove deletes a server's ai key straight away.
  • everything else is kept until you ask for it to be deleted. removing stash from a server does not delete that server's data on its own. to delete your data or a whole server's, email hi@bennett-eghan.com with the server's name.

changes

if this policy changes, the date at the top changes too. big changes will also be noted in the project's github repository.
